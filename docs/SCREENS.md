## 학생 화면

### 로그인 (`Login.jsx`)
- **참가 코드 입력 + [입장]** — 서버(`login_team`)가 코드를 검증한다. 코드가 곧 신원이다.
- 다크/라이트 토글. 틀린 코드면 에러 문구. 한 번 입장하면 새로고침해도 자동 재로그인(localStorage).

### 헤더 (`Header.jsx`) — 상단 고정
왼쪽부터: **팀명 · 라운드/연도 · 거래 타이머 카운트다운**, 오른쪽에 배지·버튼·계좌 요약.
- **거래 타이머** — [타이머 시작]으로 열린 동안 남은 시간을 센다. 끝나면 "거래 마감". 표시용이고 판정은 서버.
- **순위 배지** — 탭하면 전체 조 순위 팝업(`RankingModal`).
- **내 힌트 버튼** — 탭하면 내 힌트 팝업(`HintModal`). 새 힌트가 오면 개수 뱃지 + 도착 토스트.
- **속보 종** — 탭하면 공통 속보 팝업(`BroadcastModal`).
- **계좌 요약** — 평가금액 · 주문가능(예수금) · 총손익(색: 빨강 이익/파랑 손실).
- 다크/라이트 토글 · [로그아웃].

### 종목 리스트 (`StockList.jsx`) — 왼쪽
- 종목마다 **이름 · 현재가 · 등락률**(빨강 상승/파랑 하락). 탭하면 가운데 차트가 그 종목으로 바뀐다.
- **거래정지**(가격 0) 종목은 "거래정지" 태그. **상장 예정**(`listed_from_round` 이전)은 목록에서 숨김.
- 보유 중이면 보유 주식 수 표시. 하단에 **[MY · 내 계좌]** 버튼.

### 차트 (`Chart.jsx`) — 가운데
- 상단: 종목명 · 시장(KOSPI) · **현재가 · 등락**. **[재무제표]** 버튼(→ `FinancialModal`).
- **그리기 도구** — 펜 · 추세선 · 지우개. 차트에 손으로 표시(태블릿 터치 대응). 좌표는 정규화 저장.
- **봉 주기** 전환(일/주/월/년) — *지금은 전부 같은 1년 구간을 해상도만 바꿔 그린다(알려진 껍데기).*
- 캔들 + 이동평균선 + 현재가 선. 차트 방향은 **실제 등락과 일치**(테스트로 고정).

### 주문 패널 (`OrderSheet.jsx`) — 오른쪽
- **매수** 섹션 — 비율 버튼(10/25/50/최대) · 수량 스테퍼(−/+·직접입력) · 예상 매수금액 · **[매수]**.
- **매도** 섹션 — 동일 구성 · **[매도]**. (매수·매도가 고정 배치라 스크롤이 안 생긴다.)
- 누르면 **즉시 체결**(예수금·보유 즉시 반영). 타이머가 닫혀 있으면 버튼 잠금 + "거래 대기/마감" 안내.
  거래정지 종목은 매매 불가 안내.
- 하단에 **보유종목 목록**(종목·보유·평가). 처음 사용자를 위한 짧은 안내.

### 팝업(모달)
| 팝업 | 무엇 |
|---|---|
| `FinancialModal` 재무제표 | 종목 소개 + 연도별 5지표(매출·영업이익·순이익·부채비율·ROE). **현재 라운드 초과 연도는 가림**(스포일러 차단). 지표 설명 토글 |
| `HintModal` 내 힌트 | 등급(S~D)·라운드·헤드라인·관련 종목 카드. **호재/악재는 안 보여줌**(학생이 판단). 관련 종목 탭하면 이동 |
| `BroadcastModal` 속보 | 강사가 전체에 보낸 한 줄 알림(최신순) |
| `MyModal` MY 계좌 | 요약 바 + 3탭: **보유종목**(평가손익) / **체결내역**(체결 시점·구분·금액·실현손익) / **수익률**(로그 자산 곡선 ↔ 라운드별 % 막대 토글) |
| `RoundModal` 라운드 요약 | [연도 넘기기] 직후 자동. 새 연도 · 내 평가금액 변동 · 보유 최고/최저 등락 |
| `FinalModal` 대회 종료 | [대회 종료] 시 자동. 내 최종 순위·자산·수익률 + **전체 조 순위표**(2025 기준). 재접속해도 종료 상태면 뜸 |
| `RankingModal` 순위 | 전체 조 순위·평가금액·수익률(내 조 강조) |

## 관리자 화면 (`/?admin=1`)

### 로그인 (`Admin.jsx`)
- **관리자 비밀번호** 입력. 서버(`verify_admin`)가 대조. 세션 유지(sessionStorage).
- 탭(두 그룹, 사이드바): **[대회 운영]** 진행 · 리더보드 / **[게임 준비]** 데이터셋 · 종목·가격 · 재무·시황 · 힌트 · 조 관리. 각 탭 상단에 한 줄 도움말.

### 진행 탭 (`AdminProgress.jsx`) — 대회를 굴리는 곳
- **[연도 넘기기]** — 확인 모달 후 `advance_round`. 다음 연도 가격 공개 + 직전 라운드 스냅샷 +
  (R2부터) 힌트 자동 배분. 누른 뒤 **리더보드에서 순위 변동을 확인**하고 타이머를 연다.
- **[타이머 시작]** — 거래 창 열기(`start_round_timer`). **분 단위 입력(기본 10)**. 카운트다운 시작.
- **[대회 종료]** — `admin_end_game`. 최종 연도(2025) 공개 + 최종 정산 + 전 학생 종료 모달.
- **[게임 리셋]** — `reset_game`. **RESET 입력** 확인 후 거래·보유·힌트·속보 삭제, 예수금=시드, R0으로.
- **공통 속보** — 한 줄 발송 / 회수.
- **이번 라운드 거래 현황** — 조별 거래 수 등 실시간.

### 힌트 탭 (`AdminHints.jsx`)
- **라운드별 힌트 풀** 목록 + **힌트 편집기**(추가/수정/삭제: 라운드·등급·문구·impact·관련 종목).
- **조별 수동 지급 / 취소** — 특정 힌트를 특정 조에 더 준다(자동 배분의 보조).
- **[자동 배분 미리보기]** — 다음 라운드 진입 시 예상 배분표(순위·조·평가금액·등급·받을 힌트).
  현재 순위 기준이라 연도를 넘기면 달라질 수 있다는 경고 포함.

### 조 관리 탭 (`AdminTeams.jsx`)
- **조 추가 / 삭제**. **시드머니 설정** — 단, **게임 시작 전(R0)에만**(시작 후엔 거부).
- 조별 현황 표 — 예수금 · 평가금액 · 수익률 · 이번 라운드 거래 · 힌트 수.

### 종목·가격 탭 (`AdminStocks.jsx`)
- **연도별 가격 인라인 편집** — 0/빈칸 = 거래정지. **소급 안 됨** 경고(이미 체결된 거래엔 영향 없음).
- **종목 추가 / 수정 / 삭제**(`StockEditor`). *참고: `listed_from_round`·`sector`는 이 화면에서 못 바꾼다
  — 시드/직접 SQL 영역(→ DATA_GUIDE).*

### 리더보드 탭 (`AdminBoard.jsx`)
- 순위 · 등락(▲▼) · 평가금액 · 수익률. **큰 글씨 모드**(프로젝터로 학생에게 순위 보여줄 때).

## 실시간 신호 (참고)
화면들은 `signals` 테이블 + Supabase Realtime으로 서로 갱신된다. 신호를 받으면 각자 필요한 것만
RPC로 다시 가져온다. 종류: `round_advanced` · `timer_started` · `game_ended` · `game_reset` ·
`hints_changed` · `stocks_changed` · `teams_changed` · `broadcast`.
