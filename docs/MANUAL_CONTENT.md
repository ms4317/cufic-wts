# 콘텐츠 제작 매뉴얼 (MANUAL_CONTENT)

> **대상: 개발을 몰라도 되는 콘텐츠 제작자(교보재팀).** 관리자 화면만으로 새 게임 데이터를 처음부터
> 끝까지 만드는 법. **실제 화면·버튼·입력칸 기준**이고, 매 단계에 예시가 있다.
> (갱신: 2026-07-28 · 콘텐츠 DB 이관 + 데이터셋 기준)

관리자 화면 접속: **`배포주소/?admin=1`** → 비밀번호 입력. 위쪽에 탭이 있다:
**진행 · 힌트 · 조 관리 · 종목·가격 · 재무·시황 · 데이터셋 · 리더보드**

> 💡 **작업 전에 반드시 게임이 "시작 전(ROUND 0)" 상태여야** 게임 설정·시드 등을 바꿀 수 있다.
> 진행 중이면 [진행] 탭 → [게임 리셋]으로 되돌린 뒤 작업한다. (리셋은 콘텐츠는 안 지우고 진행 상태만 지운다.)

---

## 1. 데이터의 구성 요소 — 한 게임이 뭘로 이뤄지나

| 요소 | 관리자 탭 | 학생 화면 어디에 보이나 |
|---|---|---|
| **게임 설정** (라운드 수·연도·최종연도·시드·타이머) | 진행 → 게임 설정 | 헤더의 ROUND/연도, 거래 타이머 `[스크린샷: 학생 헤더]` |
| **종목 + 연도별 가격** | 종목·가격 | 왼쪽 종목 목록·가운데 차트·현재가 `[스크린샷: 학생 종목목록/차트]` |
| **종목 한 줄 소개** | 종목·가격 (종목 편집기) | 재무제표 팝업 맨 위 `[스크린샷: 재무제표 팝업]` |
| **재무제표** (연도×5지표) | 재무·시황 | [📈 재무제표] 버튼 → 팝업 표 `[스크린샷: 재무제표 팝업]` |
| **시황(거시지표)** (연도별) | 재무·시황 | 헤더 [📈 시황] 버튼 → 팝업 `[스크린샷: 시황 팝업]` |
| **힌트** (등급·문구·관련종목) | 힌트 | 헤더 [내 힌트] 버튼 → 팝업(조마다 다름) `[스크린샷: 힌트 팝업]` |
| **조 / 참가 코드** | 조 관리 | (대회 때 생성. 콘텐츠 아님) |

> ⚠ **[개선 필요] 업종(sector)** 은 종목 편집기에 입력칸이 있지만 **학생 화면 어디에도 표시되지 않는다.**
> 지금은 채워도 안 보이니 비워둬도 된다(§끝 "발견된 문제" 참고).

## 2. 만드는 순서 (이 순서를 지켜야 한다)

**게임 설정 → 가격 → 소개 → 재무 → 힌트 → 시황 → 데이터 점검 → 데이터셋 저장**

가격을 먼저 완성해야 하는 이유: **가격표가 게임의 뼈대**다. 소개·재무·힌트·시황이 전부 "이 종목이 이
해에 오른다/내린다"는 가격 스토리에서 파생된다. 가격을 나중에 바꾸면 나머지를 다 다시 맞춰야 한다.

---

### ① 게임 설정 — [진행] 탭 → "게임 설정 (시작 전에만)"

`[스크린샷: 진행 탭 게임 설정 카드]`

1. [진행] 탭으로 간다. 아래로 내리면 **게임 설정** 카드가 있다(시작 전 상태에서만 보인다).
2. **[설정 편집]** 을 누르면 입력칸이 열린다:
   - **라운드 수** — 예: `5`
   - **라운드별 연도** — R1~R5 각 칸에 연도. 예: `2020 2021 2022 2023 2024`
   - **최종 정산 연도** — 마지막 라운드 다음 해. 예: `2025` (매매 없이 최종 순위만 낸다)
   - **기본 시드머니** — 조를 만들 때 기본 원금. 예: `100000000` (1억)
   - **타이머(분)** — 라운드당 거래 시간. 예: `10`
3. **[설정 저장]**.

> **왜 먼저?** 여기서 정한 연도들이 이후 가격·재무·시황 편집기의 "연도 칸"을 만든다. 연도를 나중에
> 바꾸면 이미 입력한 가격이 옛 연도 키에 남아 화면에서 사라질 수 있다. **연도는 여기서 확정하고 시작.**

---

### ② 가격 시나리오 — [종목·가격] 탭 (가장 중요)

`[스크린샷: 종목·가격 탭 목록 + 종목 편집기]`

**[+ 종목 추가]** 또는 기존 종목의 **[수정]** 을 누르면 편집기가 열린다:
- **종목코드** — 예: `S01` (한 번 정하면 못 바꾼다. 짧게)
- **종목명** — 예: `승주보험`
- **한 줄 소개** — (③에서 설명)
- **업종** — (지금은 학생 화면 미표시, 비워도 됨)
- **상장 라운드** — 이 라운드부터 목록에 나타남. 보통 `1`. 중간 상장이면 `3` 등
- **연도별 가격** — 각 연도 칸에 원 단위 정수. 예: 2020 `29300`, 2021 `35000`, …

**가격 규칙**
- 라운드 연도 + 최종 연도까지 **빈칸 없이** 채운다.
- **0 또는 빈칸 = 거래정지**(매수·매도 차단, 평가액 0). 상장폐지를 이렇게 표현한다.
- **상장 라운드(예: 3) 이전 연도는 비워도 된다**(그 전엔 목록에 안 나옴 = 신규상장).

**설계 요령 — 종목 유형을 의도적으로 섞어라** (작년 2025 데이터 예시)
| 유형 | 목적 | 예시(현 데이터) |
|---|---|---|
| **급등주** | 역전의 재미 | D게임즈(신작 대박), 큐픽플랫폼 |
| **안정주** | 대조군 | 승주보험, 백만전자 |
| **몰락주** | 리스크 교육 | F모빌리티(2021 급등→2025 0원) |
| **상장폐지** | 0원 처리 | 양재금융(2024부터 0) |
| **신규상장** | 후반 변수 | M증권(S13, R3 상장) |

> 💡 **급등 후 폭락**(F모빌리티: 30,900→187,700→…→0)처럼 한 종목 안에서 드라마를 만들면 "몰빵의
> 위험"이 자연스럽게 교육된다.

---

### ③ 종목 소개 — [종목·가격] 탭, 종목 편집기의 "한 줄 소개"

같은 편집기(②)의 **한 줄 소개** 칸에 적는다. 학생은 재무제표 팝업 맨 위에서 본다.

- **가격 스토리와 모순 없게.** 몰락할 회사엔 복선을 깐다.
  - F모빌리티(몰락) → `전기 스쿠터·공유 모빌리티 스타트업이에요. 미래 성장 기대로 주목받았어요.`
  - 양재금융(폐지) → `공격적인 투자로 유명한 금융 회사예요. 벌 때는 크게 벌지만 빚도 많아요.`
- **호재/악재를 대놓고 쓰지 않는다** — 판단은 학생 몫.

---

### ④ 재무제표 — [재무·시황] 탭 → "재무제표 · 종목별"

`[스크린샷: 재무·시황 탭 재무제표 편집]`

1. [재무·시황] 탭 → 아래쪽 **재무제표 · 종목별**.
2. **종목 드롭다운**에서 종목을 고른다.
3. 연도마다 5지표 칸을 채우고 **[저장]** (그 해만 저장). 미상장/폐지 연도는 **[비움]** (행 삭제 = 화면에서 '-').
   - **매출액 · 영업이익 · 당기순이익** = 억원 (적자면 **음수**, 예: `-420`)
   - **부채비율 · ROE** = %

> ⚠ **[개선 필요] 재무 편집이 [종목·가격] 탭이 아니라 [재무·시황] 탭에 있다.** 종목별로 오가며
> 입력해야 한다(§끝 참고).

**가격 방향과 실적 방향을 맞춘다 — 유형별 패턴**
| 유형 | 재무 패턴 예시 |
|---|---|
| 안정주 | 매출·이익 **꾸준히 증가**, 부채비율 낮게(90% 등), ROE 8~11% |
| 몰락주 | 매출은 커도 **영업이익 적자**, **부채비율 급등**(210→780%), ROE 마이너스 |
| 바이오/성장주 | **적자인데 주가는 급등**(임상 기대) — 재무만 보면 위험해 보이게 |
| 폐지 직전 | 폐지 연도는 **[비움]**(데이터 없음) |

---

### ⑤ 힌트 — [힌트] 탭 (별도 상세: §3)

가장 중요하고 실수하기 쉬운 절이라 **아래 §3에서 따로** 설명한다.

---

### ⑥ 시황(거시지표) — [재무·시황] 탭 → "시황 (거시경제) · 연도별"

`[스크린샷: 재무·시황 탭 시황 편집]`

1. [재무·시황] 탭 → 위쪽 **시황 (거시경제) · 연도별**.
2. 연도마다 칸을 채우고 **[저장]**:
   - **한 줄 시황** (예: `인플레이션 급등, 금리 인상 시작 — 성장주 조정`)
   - **기준금리 · GDP성장률 · 실업률 · 물가상승률** = % / **환율** = 원/$ / **국제유가** = $
3. **종목 등락과 방향을 맞춘다.** 실제 역사 기반이면 사실에 가깝게.
   - 예: 금리 급등(0.5→3.3) + 물가 급등(0.5→5.1) 해엔 성장주(F모빌리티 등)가 꺾이도록 가격을 짜둔다.

---

### ⑦ 데이터 점검 → 데이터셋 저장

`[스크린샷: 진행 탭 데이터 점검 결과]`  `[스크린샷: 데이터셋 탭]`

1. [진행] 탭 → **[데이터 점검 실행]**. 결과 목록에서:
   - **오류(빨강)** = 반드시 고친다 (특히 "힌트 태그 up인데 실제 down" 같은 방향 불일치).
   - **참고(회색)** = 의도된 것이면 무시 가능 (예: "양재금융 R5 거래정지").
2. 오류 0이 되면 [데이터셋] 탭에서 저장:
   - **편집 중이던 데이터셋에 반영**하려면 위쪽 "지금 편집 중" 옆 **[💾 저장]**.
   - **새 데이터셋으로 만들려면** 이름·설명 입력 후 **[+ 새 데이터셋으로 저장]** (그게 편집 중이 된다).
3. **[내보내기]** 로 `.json` 백업을 받아둔다(팀 공유·인수인계용).

## 3. 힌트 제작 상세 (가장 중요)

편집: [힌트] 탭 → 힌트 목록 아래 **작성·수정** 편집기. 입력칸:
**라운드 · 등급(S/A/B/C/D) · 문구(headline) · impact(호재/악재/중립) · 관련 종목**

`[스크린샷: 힌트 탭 편집기 + 미리보기]`

### 타이밍 — "R라운드 힌트 = 그 해 → 다음 해 예고"
- **R2 힌트**는 R2(예: 2021)에 뜨고 **2022의 등락**을 예고한다. **R1엔 힌트가 없다**(첫 배분은 R2).
- 그래서 힌트의 impact·관련 종목은 **관련 종목의 그 해→다음 해 실제 가격 방향과 반드시 일치**해야 한다.
  - 안 맞으면 [데이터 점검]이 **오류**로 잡고, 힌트 목록에 **⚠ 등락 불일치** 배지가 뜬다.

### impact (호재/악재/중립)
- **호재(up)** = 다음 해 오름 / **악재(down)** = 내림 / **중립(flat)** = 시장 전반·방향 없음.
- **학생에겐 호재/악재가 안 보인다.** 문구와 재무·시황으로 학생이 스스로 판단한다. impact는 제작자용
  방향 태그(검증에 쓰임).

### 등급별 문구 예시 (현 데이터, R2·2021 → 2022 예고)
| 등급 | 성격 | 예시 문구 | impact / 관련 |
|---|---|---|---|
| **S** | 가장 확실·강력 | "D게임즈 신작, 사전예약 서버가 마비됐다… 업계 '역대급 흥행' 확신" | 호재 / D게임즈 |
| **A** | 강하지만 조건부 | "거품 논란의 모빌리티 업계, 투자금이 마르고 있다는 소문 — F모빌리티 자금난설" | 악재 / F모빌리티 |
| **B** | 방향은 뚜렷, 대상 넓음 | "바이오 임상 발표 시즌 도래… 일부 바이오 기업에 큰 장이 설 것" | 호재 / 바이오주 |
| **C** | 애매·해석 필요 | "작년에 SNS에서 유행한 것들, 올해도 유행하리란 법은 없다" | 악재 / 관련주 |
| **D** | 힌트인 듯 아닌 듯 | "시장이 흔들릴 때는 오히려 금융이 웃는다는 옛말이 있다. 늘 맞는 말은 아니지만." | 호재 / 금융주 |

> 좋은 등급일수록 **구체적·확신에 찬** 문구, 낮은 등급일수록 **모호·양시양비**. 하위권 조가 좋은 힌트를
> 받으니(아래), S는 "거의 정답"에 가깝게, D는 "곱씹어야 하는" 수준으로.

### 개수 규칙 — **현재 배분 방식(라운드로빈) 기준**
- **라운드당 힌트 개수는 자유.** 등급별 1개일 필요 없다. 원하는 만큼 만든다.
- [연도 넘기기] 때, 그 라운드 힌트 풀을 **등급 좋은 순(S→D)**으로 줄 세워 **순위 꼴찌부터 1위 방향으로
  한 장씩 라운드로빈**해 **전부** 나눠준다. → **하위권일수록 좋은 힌트 + 더 많은 개수.**
- **[자동 배분 미리보기]**([힌트] 탭)에서 조별로 뭘 몇 개 받을지 표로 확인할 수 있다.
- 요령: 조 수보다 힌트를 몇 개 더 만들면 하위권이 2장씩 받아 역전 기회가 커진다. (예: 7조 × 11힌트 →
  꼴찌 2장(S+C), 1위 1장(C))

## 4. 검증 체크리스트 (인쇄용)

새 게임을 다 만든 뒤, [진행] → [데이터 점검] 전후로 종이에 대고 확인:

- [ ] 게임 설정: 라운드 수·연도·최종연도·시드·타이머가 의도대로
- [ ] 모든 종목이 **라운드 연도 + 최종 연도** 가격을 빠짐없이(또는 의도된 0/빈칸)
- [ ] 상장 라운드 이전 연도만 비어 있고, 그 외 빈칸 없음
- [ ] 모든 종목에 **한 줄 소개**
- [ ] 재무: 등장 연도마다 5지표(또는 미상장/폐지 연도는 비움). 부채비율 음수 없음
- [ ] 시황: 모든 연도에 6지표 + 한 줄 시황
- [ ] **힌트 방향 = 실제 등락** ( ⚠ 배지·오류 0 )
- [ ] R2~R마지막 라운드에 힌트가 **최소 조 수 이상** (라운드로빈으로 전부 지급되게)
- [ ] R1엔 힌트 없음
- [ ] **[데이터 점검] 오류 0** (참고만 남음)
- [ ] [데이터셋]으로 **저장 + .json 내보내기**

## 5. 만들다 발견된 문제 (제작에 영향)

- **[개선 필요] 업종(sector)** — 종목 편집기에 입력칸은 있으나 학생 화면에 안 보인다. 지금은 비워도 무방.
- **[개선 필요] 재무 편집 위치** — [재무·시황] 탭의 종목 드롭다운 방식. 종목별로 오가며 입력해야 함
  (종목·가격 탭에 종목별 [재무제표 편집] 버튼이 있으면 더 편함).
- **[주의] 데이터 점검은 수동** — 저장할 때 자동으로 막아주지 않는다. **반드시 [데이터 점검]을 눌러**
  확인해야 한다(힌트 목록의 ⚠ 배지만 자동 표시).
- **[주의] 연도 변경 시 데이터 고아** — 게임 설정에서 연도를 바꾸면, 이미 입력한 가격·재무·시황이 옛
  연도 키에 남아 화면에서 사라질 수 있다. **연도는 처음에 확정**하고 콘텐츠를 만든다.
