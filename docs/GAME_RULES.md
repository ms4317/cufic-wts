# 게임 규칙서 (GAME_RULES)

> **갱신: 2026-07-27** · 게임 모델 **v3**(즉시 체결 + 라운드 타이머).
> 확정된 규칙과 아직 미확정인 규칙을 구분해 적는다. 미확정은 `[팀 확인 대기]`로 표시한다.
> *왜* 이렇게 정했는지는 [DECISIONS.md](DECISIONS.md), *운영 절차*는 [OPERATIONS.md](OPERATIONS.md).

CUFIC WTS는 청소년 교육용 **라운드제 모의투자**다. 학생이 조를 이뤄 참가하고, 강사가 라운드(연도)를
넘기면 주가가 바뀌며 손익이 난다. 재무제표와 힌트를 근거로 **판단하는 법**을 가르치는 게 목적이다.

---

## 1. 게임 모델 — 즉시 체결 + 라운드 타이머

- **즉시 체결.** 학생이 [매수]/[매도]를 누르면 서버(`place_order`)가 **그 자리에서** 체결한다.
  예수금·보유가 즉시 반영된다. 옛 "주문서 일괄 체결" 방식은 폐기됐다(→ §8).
- **거래는 타이머가 열린 동안만.** 관리자가 **[타이머 시작]**을 눌러야 거래가 열린다.
  기본 **10분**(`round_duration_seconds`=600초, 하드코딩 아님) 뒤 자동 마감된다.
- **타이머 강제는 서버.** `place_order`가 `now() < round_ends_at`을 검사한다. 마감 뒤엔 콘솔로도
  못 뚫는다(`round_closed`). 화면 카운트다운은 표시용일 뿐, 판정은 서버 시각이 한다.
- **가격 0 = 거래정지.** 매수·매도 차단, 평가액 0. (상장폐지의 표현 → §5)

### 게임 루프 (한 라운드)
```
[연도 넘기기] ─▶ 새 연도 가격 공개 + 직전 라운드 평가금액 스냅샷 + 힌트 자동 배분(R2~)
      │                     └─ 보유가 재평가돼 순위가 바뀐다
      ▼
관리자가 순위 변동 확인
      ▼
[타이머 시작] ─▶ 거래 창 열림(기본 10분) ─▶ 학생 즉시 매매 ─▶ 10분 뒤 자동 마감
      ▼
다시 [연도 넘기기] …  (R5까지 반복)
      ▼
[대회 종료] ─▶ 최종 연도(2025) 가격 공개 + 최종 정산 + 전 학생 종료 모달
```

- **리더보드는 연도가 넘어갈 때만 바뀐다.** 라운드 중엔 전 거래가 같은 가격이라 평가금액이
  안 변한다 — 순위는 [연도 넘기기]로 가격이 바뀔 때만 움직인다. **거래별 실시간 순위 갱신은 없다.**

## 2. 라운드 구성

- **총 5라운드.** 각 라운드가 한 연도에 매핑된다(`round_year_map`).

| 라운드 | 연도 | 비고 |
|---|---|---|
| R1 | 2020 | 시작. 전 조가 같은 시드로 출발 → 평가금액 전원 동률. **힌트 없음** |
| R2 | 2021 | 첫 자동 힌트 배분 |
| R3 | 2022 | (S13은 이 라운드부터 상장 — 예시) |
| R4 | 2023 | |
| R5 | 2024 | 마지막 매매 라운드 |
| — | **2025** | `final_year`. **매매 없음.** [대회 종료]가 이 가격으로 최종 정산 |

- **원금(시드).** 기본 1억(`default_seed`). 조별로 관리자가 다르게 설정 가능(하드코딩 아님).
- **금액은 원 단위 정수(bigint).** 평균단가만 numeric.

## 3. 힌트 시스템

- **등급 S / A / B / C / D.** S가 최상위(가장 좋은 힌트). 조마다 **받는 힌트가 다르다.**
- **R1 무지급.** 첫 배분은 **R2 진입** 때부터.
- **R2부터 순위 기반 자동 차등 지급 — 하위권 우대(꼴찌 = S).**
  [연도 넘기기](`advance_round`)가 새 가격을 공개한 **직후 순위**로 `distribute_round_hints()`가 자동 배분한다.
- **수동 지급은 보조.** 관리자가 특정 조에 특정 힌트를 추가로 줄 수 있다. 지급 안 된 힌트는
  어떤 경로로도 학생에게 안 보인다.
- **호재/악재는 화면에 표시하지 않는다.** 호재인지 악재인지는 **학생이 판단**한다(교육 목적).
  DB `impact` 태그는 내부 정합성 검증(태그↔다음 해 등락 일치)용으로만 쓰인다.

### 매핑 공식 `[팀 확인 대기]`
> **이 매핑 전체가 [잠정]이며 팀 컨펌 대상이다.** "직전 정산 순위 기준"을 아래처럼 해석했다.

- **순위 기준 = 새 가격 공개 직후**(leaderboard와 동일). 직전 라운드 스냅샷이 아니다.
  *왜* — R1은 전 조가 동률이라 스냅샷으로 배분하면 전원 같은 등급이 된다. 가격이 갈린 뒤라야 차등이 난다.
- **등급 구간** = `floor((순위 − 1) ÷ 조수 × 5)`, 상위부터 D→S. 동률은 같은 순위 = 같은 등급.
  - 예(8조): 1~2위 D / 3~4위 C / 5위 B / 6~7위 A / **8위(꼴찌) S**.
- **힌트 풀** — 라운드당 등급별 1개(같은 등급 조는 같은 힌트). 그 등급이 없으면 인접 등급(|Δ| 최소)으로
  대체하고, `advance_round` 응답에 경고를 실어 관리자 화면이 토스트로 알린다.
- 배분 후 `hints_changed` 신호 → 학생은 "새 힌트 도착" 토스트로 인지.
- 관리자 힌트 탭의 **[자동 배분 미리보기]**로 다음 라운드 예상 배분을 미리 볼 수 있다(현재 순위 기준,
  연도를 넘기면 가격이 바뀌어 달라질 수 있음).

## 4. 공통 속보 (broadcasts)

- 강사가 **전체 조에 동시에** 보내는 한 줄 알림. 힌트(조별 차등)와 별개다.
- 학생 화면 헤더의 종 아이콘 → 팝업(최신순). 전원 공개(격리 없음).
- 관리자 진행 탭에서 발송/회수. 발송 시 `broadcast` 실시간 신호.

---

## 5. 상장폐지 / 신규상장

- **신규상장(`listed_from_round`)** — 그 라운드 전에는 종목 목록에 **아예 안 보인다**(상장 예정).
  해당 라운드부터 노출·거래 가능.
- **상장폐지 = 가격 0.** 목록엔 남되 "거래정지" 태그, 매수·매도 차단, 평가액 0(전액 손실).
- 둘은 다르다. 서버는 가격 0으로 이미 매매를 막으므로, `listed_from_round`는 **표시상 신규/기존 구분**이다.

## 6. 밸런스 결정 — 몰빵 제한 없음

- **한 종목에 전액을 넣는 것(몰빵)도, 가격 변동폭도 제한하지 않는다.**
- 힌트를 완벽히 따르면 매 라운드 복리로 불어 최종 자산이 수백억(+수만%)까지 갈 수 있다.
  이걸 **규칙(코드)으로 막지 않는다.**
- *왜* — 극단 수익은 **힌트 설계(콘텐츠)로 조절**할 사안이다. 코드에 한도·캡을 넣으면 규칙이
  복잡해지고 데이터가 바뀔 때마다 다시 손봐야 한다. 밸런스는 힌트의 구체성·정확도와 가격 시나리오로 맞춘다.
- **코드는 표시만 개선** — 수익률 차트를 로그 스케일 + 억 단위 + 라운드별 % 막대로 바꿔 지수 성장을
  읽히게 했다. 숫자 자체는 그대로 둔다.

## 7. 확정 대기 항목 `[팀 확인 대기]`

- **힌트 매핑 공식** (§3) — 등급 구간·"직전 정산 순위" 해석 전체가 잠정.
- **순위 상시 노출 여부** — 현재는 팝업 + 리더보드. 상시 현황판 노출은 팀 결정 대기(경쟁 동기 vs 산만함).
- **콘텐츠 값** — 종목 소개·힌트 문구·재무 수치는 초안. 구조는 확정, 값은 검토 전.
- **종목명 방식** — 완전 창작 / 패러디 / 기호명 미정(현재 초안은 기호형 종목명 + S01~S18 코드).

## 8. 소멸한 규칙 (기록)

- **매도 대금을 매수 자금으로 인정하는 규칙 — 소멸.** 옛 "주문서 일괄 체결" 시절, 한 주문서 안에서
  매도 먼저→매수로 매도 대금을 매수에 쓰는 잠정 규칙이 있었다(작년 시트 수식). **즉시 체결로 전환하며
  무관해졌다** — 매수·매도가 각자 **현재 예수금**에 대해 독립적으로 판정된다. 관련 함수 `order_funds_ok`,
  테이블 `order_sheets`, 함수 `save_order_sheet`·`get_my_order_sheet`는 모두 **0016에서 삭제**됐다.
- **뉴스(전체 공개) → 등급제 힌트.** 초기 `news` 테이블(is_published 전체 공개)은 조별 차등 지급이
  안 돼 `hints`/`hint_grants` 체계로 대체됐다(0005, `news` drop).
