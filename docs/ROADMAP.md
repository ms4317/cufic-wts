## 완료

### 학생 화면 (프론트엔드 단독)

- **라운드 루프** — R1(2022)~R3(2024). 연도별 시세에서 현재가·등락 파생, 라운드 진행 시
  12종목 재평가 → 손익 발생. 라운드 전환 요약 모달(내 보유종목 기준 최고/최저, 직전 대비 변화)
- **주문** — 시장가 매수/매도, 공매도 차단, 거래정지(가격 0) 차단, 평단 재계산, 실현손익,
  확인 모달(체결 후 예수금 표시), 수량 키보드 입력 + 비율 버튼(10/25/50/최대·전량)
- **계좌** — 평가금액·총손익 파생 계산, MY 모달 4탭(보유종목·체결내역·수익률·순위)
- **차트** — 종목별 결정론적 캔들, 실제 등락 방향 반영, 5일 이동평균, 그리기(펜·추세선·지우개, 종목별 보관)
- **재무제표** — 12종목×4년×5지표, 라운드 초과 연도 차단(스포일러), 탭해서 여는 설명, 종목 한 줄 소개
- **시황 뉴스** — 라운드 필터, 호재/악재↔등락 정합, 전문 모달, 관련 종목 → 종목 이동, 도착 토스트(탭 이동)
- **조별 순위** — 헤더 배지 + 하단 상시 현황판 + MY 탭. **다른 조는 더미** (`예시` 배지로 표시)
- **테마** — 다크/라이트, CSS 변수 전면, FOUC 방지
- **태블릿** — 1024~1279 축소, 세로 회전 안내, 터치 44px, hover 전용 없음
- **접근성** — 모달 포커스 트랩 + 닫을 때 복귀

### 품질 장치

- **Vitest 89개** — 계좌 파생, 주문 한도, 데이터 정합성(뉴스↔주가 전수 대조), 과거 버그 4건 회귀
- **actions.js** — 상태 조작을 async `{ok, error}` 계층으로 분리. Supabase 교체 지점
- **git** — 첫 커밋 완료. `.env` 커밋 차단

## 대기 (일정 미정)

- **가상 종목 데이터 이식** — 지금 데이터는 실제 종목명 + **검증되지 않은** 주가·재무.
  **실제 수업 전 반드시 교체.** 종목명 방식(창작/패러디/기호) 미정. 시드 스크립트 교체로 처리
- **실기기 테스트** — 실제 태블릿에서 그리기·터치 영역·회전 확인. 지금은 헤드리스 브라우저 검증만
- **교육장 와이파이 확인** — 클라우드 Supabase 접속 가능 여부. 동시 접속 규모(조 개수) 미정
- **배포** — Vercel 등 미정
- **순위 상시 노출 유지 여부** — 팀 결정 대기. 일단 유지
- **봉 주기 실데이터화** — 일/주/월/년이 전부 같은 구간. 알려진 껍데기
- **파일 정리** — `index.css` 1,400줄 분리, `data.js` 콘텐츠 분리. 서버 연동 뒤로

## 알려진 위험

1. **검증되지 않은 데이터** — 학생이 지어낸 재무 수치를 사실로 배운다. 가상 종목 이식 전까지 데모 전용
2. **순위판의 가짜 조** — 서버 전에 수업에 쓰면 존재하지 않는 조와 비교하게 된다
3. **dev/prod 마이그레이션 동기화** — 대회 직전 prod 적용이 처음이 되지 않도록, 미리 한 번 리허설 필요
