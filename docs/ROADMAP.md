## 완료

### 백엔드 (Supabase, 프로젝트 `cufic_wts`)
- **마이그레이션 17개**(0001~0017) 전부 remote 적용. `game_state`(타이머·`final_year`·`is_ended` 포함) /
  `stocks` / `teams` / `positions` / `trades` / `round_snapshots` / `hints` / `hint_grants` / `signals` /
  `broadcasts` / `private.config`. **`order_sheets`·`news`는 삭제됨.**
- **RLS** — 읽기만 선별 허용, 쓰기 정책 없음(= RPC로만). `teams`·`hints`·`hint_grants` 직접 조회 차단.
- **즉시 체결 + 타이머** — `place_order`(`now() < round_ends_at` 서버 강제) / `advance_round`(가격 공개 +
  스냅샷 + 자동 힌트) / `start_round_timer`(분 단위) / `admin_end_game`(최종 정산, R5·최종 스냅샷).
- **힌트 자동 차등 지급** — `distribute_round_hints`(R2~, 꼴찌=S). 수동 지급 보조.
- **관리자 RPC** — 전부 `p_admin_secret` + `private.verify_admin`(fail-closed, `private` 스키마).
- **실시간** — `signals` + Realtime, 신호 → 각자 RPC 재조회.

### 학생 화면
- 참가 코드 로그인(서버 검증)·자동 재로그인·로딩/실패/오프라인 처리.
- **즉시 매매**(비율 버튼·수량 스테퍼)·거래 카운트다운·타이머 밖 버튼 잠금.
- **힌트**(헤더 버튼→팝업, 등급 S~D, 내 조 것만, 도착 토스트, 호재/악재 미표시).
- 차트(결정론적 캔들·그리기)·재무제표(연도 스포일러 차단)·**MY 계좌 3탭**(보유/체결/**수익률 차트**).
- 조별 순위 팝업·**라운드 전환 요약**·**대회 종료 모달**·공통 속보 팝업·다크/라이트·태블릿(44px·회전 안내).

### 관리자 화면 (`/?admin=1`)
- **진행** — 연도 넘기기(확인)·타이머 시작(분 입력)·대회 종료·리셋(RESET 입력)·속보·거래 현황.
- **힌트** — 라운드별 풀 CRUD·조별 수동 지급/취소·**자동 배분 미리보기**.
- **조 관리** — 추가/삭제·시드(시작 전만)·조별 현황.

- **리더보드** — 순위 변화(▲▼)·큰 글씨 모드.

## ⚠ 실제 수업 전 필수

1. **콘텐츠 확정** — 주가·재무·힌트 문구가 **팀 검토 전 초안**이다. 검토 후 확정하고, 바뀌면
   JSON+`build-data.mjs` 수정 → `gen-seed` → 시드 재적용([DATA_GUIDE](DATA_GUIDE.md)). **종목명 방식 미정.**
2. **힌트 자동 배분 매핑 컨펌** — 등급 구간 공식·"직전 정산 순위" 해석이 `[잠정]`. 팀 확인 필요.
3. **관리자 비밀번호 재설정** — 현재 개발 기본값(약함). 강한 값으로 `set_admin_secret()` + `.env` 동시 변경.
4. **테스트 흔적 제거** — `TEST-01`·`TIGER-03` 삭제, [게임 리셋] **리허설**. **개발 DB가 곧 대회 DB다.**
5. **배포** — 호스팅 위치 미정(Vercel 등). 교육장 와이파이 Supabase 접속 확인.
6. **실기기 테스트** — 실제 태블릿 그리기·터치·회전(지금은 헤드리스만).

## 알려진 한계

1. **관리자 계정 분리가 없다** — 관리자는 비밀번호를 입력하고 서버(`verify_admin`)가 대조한다.
   `VITE_ADMIN_PASSWORD`는 코드(src)에서 참조하지 않아 **번들에 안 들어간다.** 참가 코드 인증처럼
   교육용 수준이며, 진짜 계정 분리는 Supabase Auth + service role 필요.
2. **참가 코드를 아는 사람은 그 조로 로그인할 수 있다** — 코드 기반 인증의 본질.
3. **힌트 Realtime 직접 구독 불가** — RLS 대신 RPC로 격리해서. signals 우회(신호→재조회)라 약간 지연.
4. **개발 DB = 대회 DB** — 분리된 개발 프로젝트가 없다.
5. **`current_price`의 definer 유실** — 0008의 `security definer`가 0016 재정의에서 빠졌다.
   지금은 `stocks`·`game_state`가 공개 읽기라 정상 동작하나, 그 RLS를 조이면 되돌려야 한다([STATUS](STATUS.md) §3.3).
