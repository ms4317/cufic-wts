# 강사용 매뉴얼 (MANUAL_ADMIN) — 대회 진행법

> **실제 화면·버튼 기준.** 관리자 화면 접속: **`배포주소/?admin=1`** → 비밀번호 입력.
> 왼쪽 탭은 두 묶음: **[대회 운영]** 진행 · 리더보드 / **[게임 준비]** 데이터셋 · 종목·가격 · 재무·시황 ·
> 힌트 · 조 관리 (제작 흐름 순서). 각 탭 상단엔 한 줄 도움말이 있다.
> (갱신: 2026-07-28 · 콘텐츠 DB + 데이터셋 기준)

한 줄 요약: **[데이터셋]에서 게임 데이터를 불러오고 → [조 관리]에서 조를 만들고 → [진행]에서
[연도 넘기기]와 [타이머 시작]을 번갈아 누르며 굴리다가 → [대회 종료].**

---

## A. 대회 전날까지 (준비)

### 1) 데이터 불러오기 — [데이터셋] 탭
`[스크린샷: 데이터셋 탭]`
- 위쪽에 **"지금 편집 중: ○○"** 가 보인다. 쓸 데이터셋이 그게 아니면 목록에서 그 데이터셋의 **[편집]**
  → 확인 모달 → 콘텐츠가 그 데이터셋으로 통째로 바뀌고 **게임이 시작 전(ROUND 0)으로 리셋**된다(조는 유지).
- ⚠ **[편집](불러오기)은 게임이 "시작 전"일 때만** 된다. 진행 중이면 잠겨 있다 → 먼저 [진행]에서 리셋.
- (데이터가 이미 들어 있으면 이 단계는 건너뛴다.)

### 2) 조 만들기 · 참가 코드 확인 — [조 관리] 탭
`[스크린샷: 조 관리 탭]`
- **[+ 조 추가]** → **참가 코드**(예: `TIGER-03`)·**조 이름**·**시드머니**(비우면 기본값) 입력 → [추가].
- 표에 **코드가 그대로 보인다** — 이 코드를 각 조/학생에게 나눠준다.
- 표의 **접속 열**로 각 조가 로그인했는지(당일 "다 들어왔나") 확인한다(최근 로그인이면 초록 `접속`).
- **시드머니는 시작 전에만** 표의 시드 숫자를 눌러 바꿀 수 있다.
- 검증용 조(TEST-01 등)가 있으면 **[삭제]** 로 지운다.

### 3) 게임 리셋 — [진행] 탭 → "게임 리셋"
`[스크린샷: 진행 탭 게임 리셋 카드]`
- **[게임 리셋]** → **RESET** 입력 → [초기화]. 이전 대회의 거래·보유·힌트 지급이 지워지고 R0으로.
  (종목·힌트 등 콘텐츠는 남는다.)

### 4) 데이터·설정 점검 — [진행] 탭 → "데이터 점검"
- **[데이터 점검 실행]** → **오류(빨강)가 0**인지 확인(참고는 무시 가능).
- [진행] → **게임 설정** 카드에서 라운드 수·연도·타이머(기본 10분)가 맞는지 확인.

### 5) (선택) 관리자 비밀번호 — 대회 전 강한 값으로
- 개발 기본값이면 실전 전에 바꾸는 걸 권장(방법은 [OPERATIONS.md](OPERATIONS.md) 참고).

## B. 대회 당일 (진행 순서) — 전부 [진행] 탭

`[스크린샷: 진행 탭 현재 라운드 + 거래 타이머]`

게임 루프는 **[연도 넘기기] → 순위 확인 → [타이머 시작] → 매매 → 마감** 을 라운드마다 반복.

> 💡 [진행] 탭 맨 위 **"다음 할 일"** 카드가 지금 눌러야 할 버튼 하나를 크게 강조해준다 —
> 이것만 따라 눌러도 진행된다(대회 시작 → 타이머 시작 → 다음 연도로 → … → 대회 종료).

1. **입장 확인** — 학생들이 참가 코드로 로그인. [조 관리]/[리더보드]에서 접속 확인.
2. **대회 시작** — [진행] → **[대회 시작 (ROUND 1 열기)]** → 확인 모달 → [진행]. R1(첫 연도) 가격이 열린다.
3. **거래 열기** — 아래 **거래 타이머** 카드 → **[타이머 시작 (10분)]**. 학생 매매 시작. 10분 뒤 자동 마감.
   - 시간이 모자라면 **[+ 1분]**, 빨리 끝내려면 **[− 1분]**. 다시 열려면 **[타이머 다시 시작 (10분)]**.
4. **다음 연도로** — 마감 후 **[다음 연도로 넘어가기 (순위 갱신)]** → 확인 → 다음 해 가격 공개 +
   **순위 갱신** + (R2부터) **힌트 자동 배분**.
5. **순위 확인** — [리더보드] 탭(큰 글씨 모드)으로 학생들에게 순위 변동을 보여준다.
6. **3~5 반복** — R5까지.
7. **대회 종료** — 마지막 라운드에서 버튼이 **[대회 종료]** 로 바뀐다 → 확인 → 최종 연도 가격으로
   **최종 정산**. 전 학생 화면에 **종료 결과 모달**(최종 순위·수익률)이 뜬다.

> **순서 핵심**: 연도 넘기기(가격·순위·힌트) → 확인 → 타이머 시작(거래). **타이머를 안 열면 학생은 매매
> 못 한다**(전 종목 "거래정지"처럼 보임).

---

## C. 라운드 중에 할 수 있는 것

- **속보(전체 공지)** — [진행] 탭 → 속보 입력칸에 한 줄 → **[전체 발송]**. 전 학생 화면에 **재난문자식
  팝업**으로 뜨고 종 아이콘에 보관된다. 취소는 목록의 **[회수]**. `[스크린샷: 진행 탭 속보]`
- **수동 힌트 지급** — [힌트] 탭 → 힌트 하나 선택 → 줄 조를 체크 → 지급(자동 배분의 보조).
- **거래 현황 보기** — [진행] 탭 "이번 라운드 거래 현황"에서 어떤 조가 몇 건 매매했는지.
- **타이머 ±1분** — 위 B-3.

## D. 자주 하는 실수와 대처

| 증상 | 원인 | 대처 |
|---|---|---|
| 학생이 "매매가 안 돼요" | 타이머를 안 열었음 | [진행] → [타이머 시작] |
| 전 종목이 "거래정지" | 아직 R0(시작 전)이거나 그 라운드 가격이 0 | [대회 시작]/[연도 넘기기]로 라운드를 열기 |
| 데이터셋 [편집] 전환이 잠김 | 게임 진행 중 | [진행] → [게임 리셋] 후 [편집] |
| 순위가 안 바뀜 | 라운드 중엔 가격이 안 변함(정상) | [연도 넘기기] 해야 순위가 움직임 |
| 힌트가 안 나감 | R1이거나 그 라운드 힌트가 없음 | R2부터 자동. [데이터 점검]으로 힌트 누락 확인 |
| 학생 화면이 폰에서 안 열림 | 세로 화면 미지원 | 노트북/태블릿 **가로**로 |
| 관리자 기능이 "unauthorized" | 비밀번호 불일치/미설정 | 비밀번호 확인(OPERATIONS 참고) |

> ⚠ **[연도 넘기기]와 [대회 종료]는 되돌릴 수 없다.** 넘기기 전에 순위·거래가 끝났는지 확인.
