# CUFIC WTS — 기능 · 버튼 · 화면 정리

현재 구현된 화면 구성, 버튼, 팝업과 각각의 동작을 정리한 참조 문서.
(기준: 즉시 체결 + 라운드 타이머, 5라운드 R1=2020~R5=2024 + 2025 최종 정산, 자동 힌트 배분, 공통 속보)

접속: **학생** `http://localhost:5173` · **관리자** `http://localhost:5173/?admin=1`

---

## 0. 공통

- **역할 두 개** — 학생(참가 조), 관리자(강사). 주소로 갈린다(`?admin=1`).
- **게임 상태** — 시작 전(R0) → R1~R5 매매 → 대회 종료(2025 최종 정산). 라운드마다 강사가 [연도 넘기기]→[타이머 시작]으로 진행.
- **색·용어** — 상승·매수 = 빨강 / 하락·매도 = 파랑 / 보합·중립 = 회색. 금액은 원 단위 정수.
- **거래 조건** — 관리자가 연 **타이머 동안에만** 매매 가능. 서버가 강제(마감 뒤 거부).
- **팝업은 탭/클릭으로 열고 닫는다** (hover 전용 없음). 세로 화면(1023px↓)은 회전 안내가 덮는다.

## 1. 학생 화면

### 1-1. 로그인 (`Login`)
| 요소 | 동작 |
|---|---|
| 참가 코드 입력칸 | 조 코드 입력 (예: `TIGER-03`) |
| **입장하기** 버튼 | 서버 검증 후 입장. 새로고침해도 자동 재로그인 |
| 테마 토글(우상단) | 다크/라이트 전환 |

### 1-2. 헤더 (`Header`) — 항상 상단
| 요소 | 표시/동작 |
|---|---|
| 로고 `Cufic WTS` | — |
| 팀 배지 | 내 조 이름 |
| 라운드 배지 | `ROUND N · 연도` (종료 시 `🏁 최종 · 2025년`) |
| **타이머 배지** | 거래 중 `거래 M:SS` 카운트다운(빨강) / 대기 중 `거래 대기` / 종료 시 숨김 |
| **순위 배지** `N위 / M조` | 누르면 **전체 순위 팝업**(RankingModal) |
| **내 힌트** 배지 | 우리 조에 온 힌트 개수. 누르면 **힌트 팝업**(HintModal) |
| **🔔 속보 종 버튼** | 속보가 있을 때만 표시. 새 속보 오면 **깜빡임 + 개수**. 누르면 **속보 팝업**(BroadcastModal) |
| 계좌 요약 | 평가금액 · 주문가능(예수금) · 총 손익(원·%) |
| 테마 토글 · 로그아웃 | 다크/라이트 · 로그아웃 |

### 1-3. 왼쪽 — 종목 목록 (`StockList`)
| 요소 | 동작 |
|---|---|
| 종목 행 | 종목명·코드(+보유주) / 현재가·등락률. 누르면 가운데 차트가 그 종목으로 |
| `거래정지` 태그 | 가격 0(상장폐지 등) → 매매 불가·평가 0 |
| (상장 예정 종목) | `listed_from_round` 이전 라운드엔 **목록에서 숨김**, 상장 라운드에 등장 |
| **MY · 내 계좌 / 보유종목** 버튼(하단) | **내 계좌 팝업**(MyModal) |

### 1-4. 가운데 — 차트 (`Chart`)
| 요소 | 동작 |
|---|---|
| 상단 정보 | 종목명·코드·시장·현재가·등락(또는 거래정지) |
| **재무제표** 버튼 | **재무제표 팝업**(FinancialModal) |
| 그리기 도구 | **커서 / 펜(자유) / 추세선(두 점) / 지우개** — 차트에 낙서·추세선 |
| 봉 주기 | 일 / 주 / 월 / 년 (현재는 같은 구간을 해상도만 바꿔 그림) |

### 1-5. 오른쪽 — 주문 패널 (`OrderSheet`)
| 요소 | 동작 |
|---|---|
| 상태 안내 | `거래 대기`(타이머 전) / `거래정지`(종목) / `대회가 끝났어요`(종료) |
| **매수** — 비율 버튼 | 10% / 25% / 50% / 최대 (주문가능액 기준 수량 자동) |
| 매수 — `− / +` 스텝퍼·직접입력 | 수량 조정 |
| 매수 — 예상 매수금액 | 수량×현재가 미리보기 |
| **[매수]** 버튼(빨강) | 누르는 즉시 체결. 예수금 감소·보유 증가 |
| **매도** — 평균단가·평가손익 | 보유 종목의 평단·현재 손익 |
| 매도 — 비율 버튼 | 10 / 25 / 50 / 전량 |
| 매도 — 스텝퍼·예상 매도금액 | 수량·금액 |
| **[매도]** 버튼(파랑) | 즉시 체결. 예수금 증가·실현손익 확정 |
| **보유종목** 목록 | 종목명 · 보유수량 · 평가금액. 누르면 그 종목 선택 |
| 안내 문구 | **아직 한 번도 거래 안 한 학생에게만** 표시(첫 체결 후 사라짐) |

### 1-6. 학생 팝업(모달)
| 팝업 | 여는 곳 | 내용 |
|---|---|---|
| **MY · 내 계좌** (MyModal) | 좌하단 버튼 | 요약(평가금액·주문가능·총손익·실현손익) + 탭 **보유종목 / 체결내역 / 수익률** |
| ↳ 보유종목 탭 | | 종목·보유수량·평균단가·현재가·평가손익 |
| ↳ 체결내역 탭 | | **체결 시점(R·연도+시각)** · 종목 · 매수/매도 · 체결가 · 수량 · 체결금액 · 실현손익 |
| ↳ 수익률 탭 | | 라운드별 내 자산 추이 라인 차트 |
| **조별 순위** (RankingModal) | 헤더 순위 배지 | 순위·조·평가금액·수익률 (내 조 강조) |
| **내 힌트** (HintModal) | 헤더 내 힌트 | 힌트 카드: **등급(S~D)·라운드·힌트 글·관련 종목**. **호재/악재는 표시 안 함**(학생이 판단). 관련 종목 누르면 그 종목으로 |
| **📢 속보** (BroadcastModal) | 헤더 종 버튼 | 강사가 전체에 보낸 공통 속보 목록(최신순) |
| **재무제표** (FinancialModal) | 차트의 재무제표 | 종목 소개 + 연도별 5지표(매출·영업이익·순이익·부채비율·ROE). **현재 라운드 초과 연도는 가림**(스포일러 차단) |
| **라운드 전환** (RoundModal) | 연도 넘길 때 자동 | 새 연도 + 내 평가금액 변동 + 내 종목 최고/최저 등락 |
| **🏁 대회 종료** (FinalModal) | 대회 종료 시 자동 | 내 최종 순위·자산·수익률 + **전체 조 순위표**. 종료 후 접속해도 뜸 |
| 토스트 | 이벤트 시 | 체결/속보/힌트 도착/리셋/종료 알림 |

## 2. 관리자 화면 (`?admin=1`)

### 2-0. 로그인 / 헤더
| 요소 | 동작 |
|---|---|
| 비밀번호 입력 · **들어가기** | 관리자 인증(서버 대조). 세션 동안 기억 |
| 헤더 | 로고 · `관리자` 배지 · 현재 라운드 배지 · (정산 중 배지) · 테마 · 로그아웃 |
| 탭 | **진행 / 힌트 / 조 관리 / 종목·가격 / 리더보드** |

### 2-1. 진행 탭 (`AdminProgress`)
| 요소 | 동작 |
|---|---|
| 현재 라운드 카드 | 시작 전 / `ROUND N · 연도` 표시 |
| **[대회 시작 (ROUND 1 열기)]** | 시작 전일 때. R1 개방(타이머는 아직 꺼짐) |
| **[다음 연도로 넘어가기 (순위 갱신)]** | 다음 연도 공개 → 순위 변동 + **힌트 자동 배분**(R2부터). 확인 모달 |
| **[대회 종료]** | 마지막 라운드에서. **2025 최종 정산** + 전 학생 결과 모달 |
| **거래 시간(분) 입력** | 타이머 길이 지정(기본 10) |
| **[타이머 시작]** / **[타이머 다시 시작]** | 거래 창 열기(입력한 분 적용). 카운트다운 시작 |
| **속보 · 공통 힌트** 입력 + **[전체 발송]** | 한 줄 속보를 전 조에 즉시 발송(종 알림). 목록에서 **[회수]** |
| 이번 라운드 거래 현황 | 어느 조가 몇 건 거래했는지 |
| **게임 리셋** (`RESET` 입력) | 전 조 예수금 원금 복귀 + 보유·거래·힌트지급·속보 삭제. 이중 확인 |

### 2-2. 힌트 탭 (`AdminHints`)
| 요소 | 동작 |
|---|---|
| **힌트 풀** — 라운드 탭(R1~R5) | 라운드별 힌트 목록(등급 배지·헤드라인·영향·관련종목·지급 조 수) |
| **[+ 힌트 작성]** | 힌트 편집기(라운드·등급·영향·헤드라인·관련 종목 선택) |
| 힌트 행 **수정 / 삭제** | — |
| **조별 지급** — 배분 제안 | **[하위 3개 조] [하위 절반] [무작위 3개 조] [선택 해제]** — 제안만, 확정 아님 |
| 조 체크박스 목록 | 순위·조·예수금 보며 수동 선택. 지급된 조는 **[지급됨·취소]** |
| **[N개 조에 지급]** | 선택한 조에 확정 지급 |

> 참고: R2부터 [연도 넘기기]가 **순위 기준 자동 배분**한다(꼴찌=S). 이 탭의 수동 지급은 보조.

### 2-3. 조 관리 탭 (`AdminTeams`)
| 요소 | 동작 |
|---|---|
| **[+ 조 추가]** | 코드·이름·시드머니로 조 생성 |
| 조 표 | 코드·이름·**시드(시작 전 편집)**·예수금·평가금액·수익률·이번 라운드 거래 수·힌트 수 |
| 조 **삭제** | 확인 후 삭제 |

### 2-4. 종목·가격 탭 (`AdminStocks`)
| 요소 | 동작 |
|---|---|
| **[+ 종목 추가]** | 종목 편집기(코드·종목명·한 줄 소개·연도별 가격) |
| 종목 표 | 종목·소개·연도별 가격(0=`정지`)·수정·삭제 |
| 가격 **0/빈칸** | 거래정지(신규 상장은 이전 연도 비움) |
| 시작 후 수정 경고 | 이미 체결된 거래엔 소급 안 됨 |

> 재무제표는 화면에서 편집 불가 — `src/data.js`(JSON에서 생성)로 관리.

### 2-5. 리더보드 탭 (`AdminBoard`)
| 요소 | 동작 |
|---|---|
| 순위 목록 | 순위·조·**등락(▲▼)**·평가금액·수익률·손익 |
| **[큰 글씨 (프로젝터)]** 토글 | 프로젝터용 큰 글씨 모드 |

## 3. 상태별 화면 변화 (학생)

| 게임 상태 | 학생 화면 |
|---|---|
| 시작 전(R0) | "아직 대회가 시작되지 않았어요" 배너. 매매 불가 |
| 라운드 개방·타이머 꺼짐 | `거래 대기`. 종목·차트·재무는 보임, 매매 버튼 잠김 |
| **타이머 중** | 헤더 카운트다운, 매수·매도 활성 |
| 타이머 만료 | 자동으로 `거래 대기`(버튼 잠김) |
| 연도 넘어감 | 라운드 전환 모달 + 순위·힌트 갱신 |
| **대회 종료** | 🏁 최종 정산 모달(전체 순위) + 2025 가격 공개, 매매 종료 |

## 4. 실시간 신호 (`signals`)

한 곳에서 바뀌면 다른 화면이 즉시 반영한다. 신호를 받으면 각자 자기 데이터를 다시 읽는다.

| 신호 | 언제 | 학생 반응 |
|---|---|---|
| `round_advanced` | 연도 넘김 | 새 가격·순위 반영, 라운드 전환 모달 |
| `timer_started` | 타이머 시작 | 카운트다운 시작, 매매 개방 토스트 |
| `broadcast` | 속보 발송/회수 | 종 버튼 깜빡, 속보 도착 토스트 |
| `hints_changed` | 힌트 지급(자동·수동) | 내 힌트 갱신, "새 힌트 도착" 토스트 |
| `game_reset` | 게임 리셋 | 초기화 토스트 |
| `game_ended` | 대회 종료 | 최종 정산 모달, 2025 공개 |
